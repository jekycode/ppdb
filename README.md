# Website Informasi dan PPDB Sekolah

Website profil sekolah dan pendaftaran peserta didik baru (PPDB) online yang dibangun menggunakan Next.js, TypeScript, Tailwind CSS, dan Supabase.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Backend / DB:** Supabase
- **Deployment:** Vercel
